**版本：** V2.0  
**更新日期：** 2026-05-27

## 一、页面概述

B2B 看板是 B2B 订单的统一管理页面，支持多维度搜索、场景化视图配置、批量操作等功能。

### 1.1 入口

导航路径：**首页 > 看板管理 > B2B 看板**

### 1.2 页面布局

```
┌──────────────────────────────────────────────────────────┐
│ 首页 > 看板管理 > B2B 看板                              │
├──────────────────────────────────────────────────────────┤

├──────────────────────────────────────────────────────────┤
│ 单号 [___] B2B单号 [___] 创建时间 [____~____] 订单类型  │
│ 订单状态 审核状态                                         │
```

## 二、搜索与筛选

### 2.1 基础搜索

基础搜索栏始终显示，包含 6 个常用条件：

| 字段 | 控件 | 操作说明 |
|------|------|---------|
| **单号** | 输入框 | 输入运单号，模糊匹配 |
| **B2B单号** | 输入框 | 输入B2B单号，模糊匹配 |
| **创建时间** | 日期范围 | 选择起止时间，筛选该时间段的订单 |
| **订单类型** | 下拉单选 | 选择"B2B"或"整柜" |
| **订单状态** | 下拉多选 | 可同时勾选多个状态，如"已出仓"+"已签收" |
| **审核状态** | 下拉单选 | 选择"审核通过"、"待审核"或"审核不通过" |

### 2.2 高级搜索

点击查询区右下角的 **"展开高级查询 ▼"** 可展开更多筛选条件。共 3 行：

**第 1 行（商品/渠道）：**
- `销售产品` — 下拉选择，选项来自数据
- `目的国家` — 下拉选择，选项来自数据
- `渠道代码` — 输入框模糊匹配
- `业务员` — 输入框模糊匹配
- `客户代码` — 输入框模糊匹配

**第 2 行（订单属性）：**
- `是否报关件` — 是/否
- `地址类型` — 亚马逊地址 / 私人地址 / 第三方地址
- `是否加件` — 是/否
- `是否完成增值服务` — 是/否
- `是否可配载` — 是/否
- `地址审核状态` — 已审核 / 待审核

**第 3 行（拦截/计费/时间）：**
- `是否拦截` — 是/否
- `计费结果` — 下拉选择
- `审核时间` — 日期范围选择
- `首次可配载时间` — 日期范围选择

### 2.3 查询与重置

| 按钮 | 位置 | 功能 |
|------|------|------|
| **查询** | 工具栏右侧（带🔍图标） | 按当前条件过滤列表 |
| **重置** | 查询按钮左侧 | 清空所有搜索条件，恢复到初始状态 |

## 三、场景管理

场景功能用于保存和快速切换不同的视图配置，包括筛选条件、显示列和搜索字段。

### 3.1 场景 Tab 栏

位于搜索栏上方：

- **全部订单** — 默认场景，始终存在，显示所有列和所有搜索字段
- **自定义场景** — 用户保存的场景 Tab，点击即可切换
- **+ 新建场景** — 创建新的场景配置
- **⚙编辑当前场景** — 仅在自定义场景激活时显示，用于修改场景设置

### 3.2 新建场景

1. 点击 **"+ 新建场景"**
2. 在弹出的对话框中配置：
   - **场景名称**：输入场景标识名称
   - **搜索字段**：勾选需要在搜索栏中显示的字段
   - **筛选条件默认值**：为每个搜索字段设置默认值（可选）
   - **显示字段**：选择列表需要展示的列，可调整顺序
3. 点击"确认"保存

> 提示：新建场景会**继承当前页面**的搜索条件、列配置和搜索字段选择作为默认值

### 3.3 编辑场景

1. 切换到需要编辑的场景
2. 点击 **"⚙编辑当前场景"**
3. 修改配置后点击"确认"

### 3.4 删除场景

弹框底部有"删除场景"按钮，点击后确认删除。

### 3.5 切换场景

点击任意场景 Tab，页面会自动恢复为该场景保存的：
- 搜索条件（包括输入框的值和下拉选项）
- 可见列配置
- 可见搜索字段

## 四、列自定义

### 4.1 调整列顺序

在场景编辑弹框的"显示字段"区域，每列左侧有序号标识，右侧有操作按钮：
- **↑ 上移**：将该列向前移动一位
- **↓ 下移**：将该列向后移动一位
- **✕ 删除**：将该列从列表中隐藏

### 4.2 恢复隐藏的列

被删除的列会出现在底部的"已隐藏的列"区域，点击 **"+ 列名"** 可将其重新添加到列表末尾。

### 4.3 快捷操作

- **全选**：选中所有列
- **反选**：反转当前选中状态

---

## 五、表格操作

### 5.1 行选择

每行前有复选框，支持多选。选中行数量在右上角实时更新。

### 5.2 详情与日志

每行操作列提供两个功能链接：

| 操作 | 触发事件 | 说明 |
|------|---------|------|
| **详情** | 打开订单详情弹框 | 查看订单完整信息 |
| **日志** | 打开操作日志弹框 | 查看订单操作记录 |

### 5.3 分页浏览

底部分页器支持：
- 切换页码
- 显示"共 N 条"总计
- 每页条数可配置（默认 20 条/页）

## 七、常见操作流程

### 7.1 日常查单

```
① 在"单号"输入框输入运单号 → ② 点击查询 → ③ 查看结果
或
① 选择创建时间范围 → ② 选择订单状态 → ③ 点击查询
```

### 7.2 配置个性化看板

```
① 设置常用搜索条件 → ② 隐藏不需要的列 → ③ 调整列顺序
→ ④ 点击"+ 新建场景" → ⑤ 输入场景名称 → ⑥ 确认保存
→ ⑦ 后续可直接点击场景 Tab 一键切换
```

### 7.3 批量查看订单

```
① 勾选需要查看的订单行 → ② 查看行选择计数
③ 点击某行的"详情"查看完整信息
```

## 八、注意事项

1. **搜索条件实时性**：修改搜索条件后需要点击"查询"按钮才会生效，不自动触发搜索
2. **场景保存范围**：场景仅保存筛选条件默认值，不保存当前页面的搜索输入值
3. **列顺序**：场景的列顺序在编辑弹框中通过↑↓调整，确认保存后列表会按此顺序展示
4. **数据量**：列表数据来自 `src/database/b2b-orders.json`，共 400 条示例订单
5. **高级查询**：展开/收起状态仅在当前会话有效，刷新页面后恢复收起状态

## 九、字段说明

### 9.1 列表字段

列表默认展示全部 100 个字段，涵盖以下分类：

| 分类 | 典型字段 |
|------|---------|
| **订单标识** | 运单号、B2B单号、客户单号、服务商单号 |
| **订单信息** | 创建时间、订单类型、订单来源、订单状态、审核状态 |
| **客户信息** | 客户代码、业务员、客服员、销售产品 |
| **物流信息** | 目的国家、服务渠道名称、物流方式、报关方式 |
| **收件人信息** | 收件人姓名、省/州、城市、地址、邮编、电话、邮箱 |
| **发件人信息** | 发件人公司名、姓名、电话、地址 |
| **计费信息** | 计费重、计费状态、入账结果、入账状态 |
| **费用信息** | 体积、重量、材积重、方数 |
| **时间信息** | 创建时间、审核时间、签入时间、签出时间、签收时间 |
| **货物信息** | 品名、件数、货物类型、柜量、柜型 |
| **报关信息** | 是否报关件、报关方式、清关方案、海关编码 |
| **其他** | 是否拦截、是否扣件、安检类型、Reference ID |

### 9.2 搜索字段

搜索栏共 18 个可配置的搜索条件，用户可通过场景自定义显示哪些搜索字段。

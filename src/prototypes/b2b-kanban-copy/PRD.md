## 一、需求背景

### 1.1 业务背景

国际物流B2B业务中，运营、客服、财务等角色日常需要查看订单列表，但不同角色的关注维度不同：
- **运营人员**关注订单状态、审核状态、计费结果
- **客服人员**关注运单号、客户信息、预约信息
- **财务人员**关注计费结果、入账状态、费用确认

当前订单列表的搜索条件、显示字段对所有用户固定，无法按角色或使用习惯灵活配置，导致每次查看时需反复调整搜索条件，效率低。

### 1.2 现状问题

- **搜索条件无法保存**：用户每次进入页面都需要重新输入搜索条件，重复操作多
- **显示字段固定不变**：所有用户看到相同的列，无法按需隐藏/显示字段
- **缺少个性化配置**：不同角色、不同场景下的查看视角无法快速切换
- **场景共享不便**：运营人员无法将常用的筛选视图分享给同组同事

### 1.3 需求目的

- 提供**场景管理**功能，允许用户保存/切换多套配置（搜索条件 + 显示字段 + 搜索字段可见性）
- 支持**新建场景**、**编辑场景**、**删除场景**，配置灵活
- 场景数据通过 **localStorage** 持久化，刷新页面不丢失
- 默认提供"全部订单"视图，恢复系统默认配置

## 五、流程图

### 场景管理流程

```
用户进入B2B看板页面
    │
    ▼
┌─ 右侧场景浮窗: [全部订单 ▼] [⚙ 管理场景]（可拖拽）
│
├── 下拉选择「全部订单」──→ 恢复默认搜索条件 + 全量显示字段 + 全量搜索框
│
├── 下拉选择自定义场景 ──→ 应用该场景的搜索值、可见列、可见搜索框
│
├── 点击「场景编辑」──→ 弹出场景列表弹框
│   │
│   ├── 顶部「新建场景」按钮 ──→ 弹出新建场景弹框
│   │
│   └── 点击已有场景项 ──→ 弹出编辑场景弹框
│       │
│       ├── 修改场景名称、搜索字段、筛选默认值、显示字段
│       └── 点击「保存场景」──→ 场景更新并应用
│           │
│           └── 点击「删除场景」──→ 二次确认后删除，切回全部订单
│
└── 新建场景弹框
    │
    ├── 输入场景名称
    ├── 选择搜索字段
    ├── 设置筛选条件默认值
    ├── 选择显示字段（拖拽排序）
    └── 点击「创建场景」──→ 场景保存并应用
```

## 七、功能描述

### 7.1 场景浮窗（可拖拽）

场景切换和编辑功能集成在一个可拖拽的固定定位浮窗中，位于页面右侧。

**视觉规范：**

| 元素 | 样式 |
|------|------|
| 浮窗 | `position: fixed`，width 200px，圆角8px，阴影 |
| 标题栏 | 灰色背景(#f5f7fa)，文字"场景切换"，cursor grab |
| 内容区 | padding 10px 12px，垂直排列 |
| 下拉框 | 100%宽度，选择"全部订单" + 自定义场景 |
| 管理按钮 | 全宽按钮("管理场景"，⚙ 图标) |

**交互逻辑：**

| 操作 | 触发条件 | 结果 |
|------|---------|------|
| 拖拽浮窗 | 按住标题栏拖拽 | 浮窗位置跟随鼠标移动 |
| 下拉选择"全部订单" | 在浮窗下拉框中选择"全部订单" | 重置为默认视图 |
| 下拉选择自定义场景 | 在浮窗下拉框中选择自定义场景 | 应用该场景配置 |
| 点击「管理场景」 | 点击浮窗内按钮 | 弹出 Popover 列表（见 7.1.1） |

#### 7.1.1 场景管理 Popover

当用户点击「场景编辑」按钮时，弹出场景列表弹框，用于选择要编辑的场景或新建场景。

**Popover 规范：**

| 属性 | 说明 |
|------|------|
| 触发 | 点击浮窗内"管理场景"按钮 |
| 布局 | 右侧弹出，min-width 260px |
| 底部按钮 | 无 |

**列表内容：**

| 元素 | 说明 |
|------|------|
| 「新建场景」 | 顶部虚线边框卡片，蓝色文字+图标，点击打开新建场景弹框 |
| 已有场景列表 | 每个场景显示名称、搜索字段数、显示列数；当前激活态场景左侧有蓝色圆点标记 |
| 删除按钮 | 每行右侧"删除"文字按钮，点击弹出二次确认 |
| 空状态 | 无场景时显示"暂无场景，点击上方按钮创建" |

**交互逻辑：**

| 操作 | 触发条件 | 结果 |
|------|---------|------|
| 点击「新建场景」 | 用户点击列表顶部"新建场景" | 关闭 Popover，打开新建场景弹框（预设当前页面搜索值） |
| 点击场景行 | 用户点击列表中某个自定义场景 | 关闭 Popover，打开编辑场景弹框（带入该场景已保存配置） |
| 点击「删除」 | 用户点击场景右侧删除文字 | 弹出 Modal.confirm二次确认，确认后删除并关闭 Popover |

### 7.2 新建场景弹框

**弹框规范：**

| 属性 | 说明 |
|------|------|
| 标题 | "新建场景" |
| 宽度 | 700px |
| 底部按钮 | "取消"（次要）、"创建场景"（主要） |

**弹框内容分为 4 个区：**

#### 7.2.1 场景名称

Input 输入框，placeholder="请输入场景名称"，支持回车提交。
- 必填，为空时点击保存提示"请输入场景名称"
- 限制纯文本输入

#### 7.2.2 搜索字段

标签式可点选区域，每个搜索字段对应一个标签（24个）：

| 字段键 | 显示名称 |
|--------|---------|
| waybillNo | 单号 |
| b2bNo | B2B单号 |
| orderType | 订单类型 |
| orderStatus | 订单状态 |
| auditStatus | 审核状态 |
| product | 销售产品 |
| country | 目的国家 |
| channel | 渠道代码 |
| salesman | 业务员 |
| customerCode | 客户代码 |
| isCustoms | 是否报关件 |
| addrType | 地址类型 |
| isExtra | 是否加件 |
| isValueAddDone | 是否完成增值服务 |
| isStowable | 是否可配载 |
| addrAuditStatus | 地址审核状态 |
| isIntercept | 是否拦截 |
| billingResult | 计费结果 |
| billingWeight | 计费重> |
| createTime | 创建时间 |
| auditTime | 审核时间 |
| signInTime | 签入时间 |
| stowableTime | 可配载时间 |
| firstStowableTime | 首次可配载时间 |

**交互：**
- 点击标签切换选中状态（○ 未选 / ✓ 已选）
- 选中时蓝色边框背景 (#eef3ff + #1D4CD2)
- 标题旁提供「全选」「反选」快捷操作
- 选中的搜索字段决定查询区哪些搜索框可见

#### 7.2.3 筛选条件默认值

3列网格表单，仅展示**已选中的搜索字段**对应的配置项。

**控件类型规则：**

| 字段类别 | 控件 | 说明 |
|---------|------|------|
| 文本输入 | Input | 单号、B2B单号、渠道代码、业务员、客户代码、计费重> |
| 单选下拉 | Select | 订单类型、审核状态、销售产品、目的国家、地址类型、地址审核状态、计费结果；选项含"全部" |
| 多选下拉 | Select mode="multiple" | 订单状态 |
| 是/否 | Select | 是否报关件、是否加件、是否完成增值服务、是否可配载、是否拦截 |
| 时间范围 | RangePicker | 创建时间、审核时间、签入时间、可配载时间、首次可配载时间 |

**下拉选项来源：**

| 字段 | 选项 |
|------|------|
| 订单类型 | B2B, 整柜 |
| 订单状态 | 动态从数据集的"订单状态"列去重获取 |
| 审核状态 | 审核通过, 待审核, 审核不通过 |
| 销售产品 | 动态从数据集的"销售产品"列去重获取 |
| 目的国家 | 动态从数据集的"目的国家"列去重获取 |
| 地址类型 | 亚马逊地址, 私人地址, 第三方地址 |
| 地址审核状态 | 已审核, 待审核 |
| 计费结果 | 动态从数据集的"入账结果"列去重获取（显示为"计费结果"） |

#### 7.2.4 显示字段

4列网格，展示所有可选的表格列，支持：
- **拖拽排序**：拖动手柄(⠿)拖动列标签调整列顺序
- **上/下移动**：通过按钮微调列顺序
- **移除**：点击 × 从可见列中移除
- **恢复**：被移除的列出现在下方"可添加列"区域，点击 + 恢复

标题旁提供「全选」「反选」快捷操作。

**保存逻辑：**
- 点击「创建场景」后：
  1. 生成唯一场景ID（`scenario_N` 格式）
  2. 记录场景名称、搜索字段选择、筛选默认值、显示字段列表
  3. 将场景追加到场景列表
  4. 自动激活该场景（切换Tab、应用配置）
  5. 写入 localStorage 持久化

### 7.3 编辑场景弹框

与新建弹框共用同一弹框模板，区别：

| 差异点 | 新建场景 | 编辑场景 |
|--------|---------|---------|
| 标题 | "新建场景" | "编辑场景" |
| 确认按钮文字 | "创建场景" | "保存场景" |
| 预设值 | 带入当前页面的搜索值、可见列、可见搜索字段 | 带入该场景已保存的配置 |
| 额外按钮 | 无 | 底部左侧显示「删除场景」红色危险按钮 |
| 保存行为 | 新建场景并应用 | 更新已有场景配置并应用 |

**删除场景流程：**
1. 点击「删除场景」红按钮
2. 弹出 Modal.confirm："确定要删除场景"xxx"吗？"
3. 点击「删除」确认后：
   - 从场景列表中移除
   - 若该场景为当前激活场景，切换到"全部订单"视图
   - 更新 localStorage

### 7.4 场景持久化

| 存储项 | Key | 说明 |
|--------|-----|------|
| 场景列表 | `b2b_kanban_scenarios` | 所有自定义场景数据（JSON数组），每次场景变更时更新 |
| 当前激活场景 | `b2b_kanban_active_scenario` | 激活的场景ID，刷新后自动恢复 |

**加载逻辑：**
- 组件挂载时从 localStorage 读取 `b2b_kanban_scenarios`
- 读取 `b2b_kanban_active_scenario` 确定激活哪个场景
  - 若ID为 `__default__` 或未匹配到已保存场景，使用全部订单视图
  - 若匹配到场景，应用该场景的搜索值 + 可见列 + 可见搜索字段

### 7.5 业务规则

**规则一：搜索框可见性联动**
- 查询区搜索框的显示/隐藏由场景的 `visibleSearchFieldKeys` 控制
- 未选中的搜索字段对应的 `.filter-group` 设置 `display: none`
- 切换场景时 `sfVisible()` 重新计算

**规则二：表格列联动**
- 表格列由场景的 `visibleColumnKeys` 控制
- 动态过滤 `ALL_COLUMNS` 获取当前列配置
- 操作列（详情|日志）始终显示

**规则三：搜索条件联动**
- 切换场景时自动填充搜索值到各输入控件
- 搜索条件即时生效（配合"查询"按钮触发过滤）
- 编辑场景时自动带入当前页面搜索值作为默认值

**规则四：默认视图兜底**
- 无场景时默认使用全部订单视图
- 全部订单视图固定：所有搜索字段显示、所有表格列显示、搜索条件清空
- 被删除的场景如果当前是激活态，自动回退到全部订单视图

## 九、非功能需求

### 1. 存储

- 场景数据使用浏览器 localStorage 存储
- 单场景数据大小不超过 5KB
- 场景数量上限不做强制限制，建议不超过20个

### 2. 性能

| 维度 | 要求 |
|------|------|
| 场景切换 | 下拉选择场景后配置即时生效，无感知延迟 |
| 弹框打开 | 新建/编辑弹框打开响应不超过0.5秒 |
| 拖拽排序 | 列拖拽过程中无卡顿，drop后即时更新 |

### 3. 浏览器兼容性

- 兼容Windows谷歌、火狐
- 兼容Mac谷歌、火狐、Safari
- localStorage 所有浏览器均支持

### 4. 数据安全

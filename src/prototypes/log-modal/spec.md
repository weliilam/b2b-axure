# B2B 日志记录弹框

## 📋 业务与功能

### 1.1 核心目标
> 展示订单/业务操作的历史日志记录，提供操作轨迹追溯，便于用户了解订单变更历史

### 1.2 功能清单
- **[展示日志列表]**：以表格形式展示操作日志记录
- **[分页浏览]**：支持分页查看日志记录，每页最多展示 15 条
- **[日志字段]**：显示序号、操作系统、内部操作人、外部操作人、内容、操作时间

### 1.3 交互要点
- **打开弹框**：在其他页面或弹框中点击"日志记录"触发打开
- **关闭弹框**：点击取消按钮或遮罩层关闭
- **分页切换**：点击分页器切换日志页

## 📊 内容规划

### 2.1 信息架构

```
日志记录弹框
├── 日志列表表格
│   ├── 序号
│   ├── 操作系统
│   ├── 内部操作人
│   ├── 外部操作人
│   ├── 内容
│   └── 操作时间
└── 底部操作栏
    └── 取消按钮
```

### 2.2 数据来源

- **数据类型**：列表数据
- **数据源**：模拟数据（生产环境由后端接口提供）
- **关键字段**：

| 字段名 | 显示名称 | 类型 | 说明 | 示例值 |
|--------|---------|------|------|--------|
| `seq` | 序号 | `number` | 日志编号，从 1 开始递增 | `1` |
| `os` | 操作系统 | `string` | 操作使用的操作系统名称 | `Windows 10`、`macOS`、`Linux`、`iOS`、`Android` |
| `innerOperator` | 内部操作人 | `string` | 系统内部操作人员姓名 | `张三` |
| `outerOperator` | 外部操作人 | `string` | 系统外部操作人用户名 | `admin` |
| `content` | 内容 | `string` | 详细操作内容描述 | `创建B2B订单，运单号YT2611924300300033` |
| `operationTime` | 操作时间 | `string` | 操作发生时间，格式 yyyy-MM-dd HH:mm:ss | `2026-04-29 09:31:18` |

### 2.3 内容示例

```json
{
  "logList": [
    {
      "seq": 1,
      "os": "Windows 10",
      "innerOperator": "张三",
      "outerOperator": "admin",
      "content": "创建B2B订单，运单号YT2611924300300033",
      "operationTime": "2026-04-29 09:31:18"
    },
    {
      "seq": 2,
      "os": "macOS",
      "innerOperator": "李四",
      "outerOperator": "c06901",
      "content": "提交订单审核申请",
      "operationTime": "2026-04-29 14:20:05"
    }
  ]
}
```

## 🎨 布局与结构

### 3.1 整体布局

- **布局模式**：弹框（Modal）内嵌表格
- **弹框宽度**：960px（拉宽以便尽量展示全字段内容）
- **弹框高度**：自适应，最多展示 15 条日志记录的高度（约 660px）
- **表格布局**：固定列宽，水平滚动

### 3.2 响应式适配

- 桌面端（≥1200px）：标准弹框宽度 960px
- 平板端（768-1199px）：弹框宽度 90%

## 🎨 视觉规范

### 4.1 设计规范来源

**设计规范来源**：`内置 interface-design`

### 4.2 自定义设计要点

- 弹框标题：蓝色竖线 + 标题文字 "日志记录"
- 表格样式：紧凑表格（antd Table size="small"）
- 列顺序：序号 → 操作系统 → 内部操作人 → 外部操作人 → 内容 → 操作时间
- 底部按钮：仅"取消"按钮

### 4.3 组件状态

- **弹框**：居中显示，点击遮罩可关闭
- **表格行**：hover 高亮（背景色 #f0f5ff）

## ⚙️ Axure API 说明

### 5.1 事件列表（eventList）

| 事件名称 | Payload 类型 | 触发时机 | 说明 |
|---------|-------------|---------|------|
| `onCancel` | `string` | 点击取消按钮时 | 关闭弹框 |

### 5.2 动作列表（actionList）

| 动作名称 | Params 类型 | 参数说明 | 功能描述 |
|---------|------------|---------|---------|
| `openModal` | `string` | 无 | 打开日志记录弹框 |
| `closeModal` | `string` | 无 | 关闭日志记录弹框 |

### 5.3 变量列表（varList）

| 变量名称 | 类型 | 默认值 | 说明 |
|---------|-----|-------|------|
| `modal_open` | `boolean` | `true` | 弹框是否打开 |

### 5.4 配置项列表（configList）

| 配置项名称 | 类型 | 默认值 | 说明 |
|----------|-----|-------|------|
| `title` | `string` | "日志记录" | 弹框标题 |

### 5.5 数据项列表（dataList）

**数据结构**：
```typescript
{
  logList: Array<{
    seq: number;           // 序号，从 1 递增
    os: string;            // 操作系统，如 Windows 10、macOS、Linux
    innerOperator: string; // 内部操作人
    outerOperator: string; // 外部操作人
    content: string;       // 操作内容描述
    operationTime: string; // 操作时间，格式 yyyy-MM-dd HH:mm:ss
  }>;
}
```

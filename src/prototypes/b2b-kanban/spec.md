## 场景管理

### 场景 Tab 栏
- 位于查询区下方，工具栏上方
- **全部订单** Tab：始终存在，蓝色背景白色文字（active），点击恢复默认
- **自定义场景** Tab：用户保存的场景 Tab
- **+ 新建场景**：蓝色文字链接，点击弹出编辑弹框
- 右侧操作按钮：
  - **编辑当前场景** ⚙：仅当场景 Tab 激活时显示，点击弹出编辑弹框
  - **列自定义** ▦：始终可见

### 编辑/新建场景弹框
- **场景名称**：Input 输入框
- **搜索字段**：标签式可点选区域（○ 未选 / ✓ 已选），选中时蓝色边框背景，选择哪些搜索字段在查询区显示
- **筛选条件默认值**：3 列网格表单，每个字段可编辑（Input 或 Select），支持预设搜索条件值
  - Input 字段：单号、B2B单号、渠道代码、业务员、客户代码
  - Select 字段：订单类型、订单状态、审核状态、销售产品、目的国家等
  - 是/否 Select：是否报关件、是否加件、是否仅配载等
- 底部：取消 / 保存场景 按钮

### 场景核心逻辑
- 点击场景 Tab 一键恢复该场景的搜索条件 + 可见列 + 可见搜索字段
- 保存场景时记录当前搜索条件、列设置和搜索字段选择
- 编辑场景时自动带入当前搜索值作为默认值
- 非自定义场景（全部订单 Tab）显示所有搜索字段和所有列

## 交互说明

1. **搜索** — 点击工具栏的"查询"按钮，触发 `onSearch` 事件
2. **重置** — 点击工具栏的"重置"按钮，清空所有搜索条件
3. **展开/收起高级查询** — 点击查询区底部右对齐的"展开高级查询"链接（带 ▼ 箭头），下方展开第 2-4 行高级筛选字段；点击"收起高级查询"（带 ▲ 箭头）隐藏
4. **刷新** — 刷新表格数据，重置页码
5. **分页** — 切换分页触发 `onPageChange` 事件
6. **行选择** — 支持多选，选中行数量由 `selected_count` 变量获取

## 一、需求背景

### 1.1 业务背景（可选）

国际物流B2B业务中，运单的计费重量需要根据长宽高尺寸和实际重量进行进位计算。不同国家、不同产品类型对进位规则的要求不同（如向上进位、保留整数、不进位等）。当前缺少一个统一的后台配置入口，运营人员无法自助配置规则，计费异常时需要开发介入修改，流程长、效率低。

### 1.2 现状问题（必选）

- **规则配置入口缺失**：进位规则无统一配置页面，规则变更依赖开发修改代码，响应周期长达1-2天
- **多国家规则管理低效**：当多个国家使用相同的进位规则时，需要逐条配置，无法批量处理
- **规则生命周期管理空白**：缺少查看、复制、失效等操作，无法灵活管理规则状态
- **导入导出机制缺乏**：大量规则新增时缺少批量导入能力，逐一新建效率低
- **规则冲突无法预警**：多个规则在相同国家、相同时间段内容易产生冲突，缺少校验机制，可能导致计费混乱

### 1.3 需求目的（必选）

- 提供一个**统一的规则配置管理页面**，支持运营人员自助配置各国进位规则，规则变更不再依赖开发
- 支持**新增、查看、复制、失效、批量失效、导入导出**完整的规则生命周期管理
- 支持**多国家合并配置**，相同进位规则一次配置即可覆盖多个国家
- 通过**重复校验**和**时间区间校验**防止规则冲突，避免计费异常
- 支持**状态自动计算**，根据生效时间区间自动判断规则当前是生效还是失效状态

### 功能整体交互

- **进入方式**：通过计费菜单进入进位规则管理页面
- **数据加载**：页面打开后自动加载全部规则数据列表
- **规则变更**：新增/复制/导入生成新规则后，列表自动刷新展示最新数据
- **状态判定**：规则的生效/失效状态不存储在固定字段中，而是根据当前系统时间与规则的生效时间区间动态计算
- **列表排序**：生效规则排在最前，失效规则排在最后；相同状态的规则按生效时间从新到旧排列
- **分页**：支持分页展示

## 七、功能描述

### 7.1 搜索筛选

页面顶部提供搜索筛选区，两个筛选条件之间为"且"关系（即同时满足所有条件才展示）。

| 筛选项 | 操作方式 | 规则说明 |
|--------|---------|---------|
| 国家 | 输入关键词查询 | 模糊匹配，关键词与规则中任何一个国家名称包含匹配即命中；支持清除已填关键词 |
| 状态 | 下拉选择 | 可选值：生效、失效；默认不选择状态时（即查全部），展示所有规则的记录 |

**搜索条件组合规则**：
- 国家为空 + 状态为空：展示全部规则
- 国家为"英国" + 状态为空：展示包含英国的全部规则（不论生效或失效）
- 国家为空 + 状态为"生效"：展示当前状态为生效的全部规则
- 国家为"英国" + 状态为"生效"：展示包含英国且当前为生效的规则

**异常场景**：
- 搜索无结果：展示空状态提示"未找到符合条件的规则"
- 国家输入非法字符（如特殊符号）：按字符串模糊匹配处理，不做过滤或拦截

### 7.2 操作按钮

列表上方横向排列操作按钮：

| 按钮 | 触发条件 | 功能说明 |
|------|---------|---------|
| 新增 | 始终可用 | 打开新增规则表单弹框 |
| 批量失效 | 勾选至少一条规则时可用 | 将选中的多条规则置为失效；未勾选任何规则时按钮置灰不可点击 |
| 模板下载 | 始终可用 | 下载指定格式的Excel导入模板 |
| 导入 | 始终可用 | 上传Excel文件，批量导入规则 |

### 7.3 规则列表

#### 列表列定义

| 列名 | 说明 |
|------|------|
| 勾选框 | 用于多选行，勾选后可进行批量操作；列表顶部提供全选/取消全选功能 |
| 序号 | 从1开始递增显示 |
| 状态 | 根据当前系统时间与规则的生效时间区间动态计算：当前时间在区间内=生效（绿色标识），当前时间不在区间内=失效（灰色标识） |
| 国家 | 规则适用的国家列表，多个国家之间用逗号分隔；国家名称数量较多时超出显示区域的部分以省略号截断，鼠标悬停可浮层查看完整列表 |
| 长宽高进位规则 | 尺寸计费时的进位方式 |
| 长宽高进位值 | 进位基准值，仅当进位规则为"向上进位"时展示该列内容，其他进位规则时该列留空 |
| 实重进位规则 | 实际重量计费时的进位方式 |
| 实重进位值 | 进位基准值，仅当进位规则为"向上进位"时展示该列内容，其他进位规则时该列留空 |
| 生效时间 | 规则生效的起始时刻（精确到秒） |
| 失效时间 | 规则失效的时刻（精确到秒） |
| 操作 | 查看、复制、失效三个操作按钮 |

#### 操作列逻辑

| 按钮 | 显示条件 | 说明 |
|------|---------|------|
| 查看 | 所有行，始终显示 | 点击后弹出只读弹框展示该规则全部字段 |
| 复制 | 所有行，始终显示 | 点击后打开新增弹框并预填该规则的所有字段 |
| 失效 | 仅当前状态为"生效"的行显示 | 点击后弹出失效时间选择弹框；失效状态的行不显示此按钮 |

**异常场景**：
- 用户先加载列表，列表中某条规则在查看过程中状态发生了变化（失效时间已过）：不会自动刷新，需用户手动刷新页面或重新查询后才能看到最新状态
- 复制一条已失效的规则：复制弹框预填该规则的所有字段（包括生效时间区间），用户可以修改后保存为新规则

### 7.4 新增/复制规则

#### 表单字段

| 字段 | 操作方式 | 规则说明 |
|------|---------|---------|
| 国家 | 多选下拉，支持搜索 | 可同时选择多个国家，提交后合并为一条记录；下拉选项展示国家名和二字码，支持按国家名或二字码搜索 |
| 长宽高进位规则 | 下拉单选 | 必填。可选值：向上进位、保留整数、不进位 |
| 长宽高进位值 | 下拉单选 | 仅当"长宽高进位规则"选择"向上进位"时显示该字段，其他规则时隐藏；必填。可选值：1、0.5、0.2、0.1 |
| 实重进位规则 | 下拉单选 | 必填。可选值：向上进位、保留整数、不进位 |
| 实重进位值 | 下拉单选 | 仅当"实重进位规则"选择"向上进位"时显示该字段，其他规则时隐藏；必填。可选值：1、0.5、0.2、0.1 |
| 生效时间 | 时间区间选择控件 | 一个控件同时选择生效起始时间和失效结束时间（精确到秒） |

#### 提交校验规则

**校验一：必填校验**
- 所有显示的字段均为必填（包括条件显示的进位值字段）
- 任一必填字段为空时，阻止提交，错误提示聚焦到第一个未填写的字段

**校验二：生效时间不能大于当前时间**
- 生效起始时间不能晚于当前系统时间
- 违反时提示"生效时间不能大于当前时间，请检查！"，阻止提交
- 特殊场景：如果用户先选了未来的时间，被拦截后调整时间，需要重新触发所有校验

**校验三：生效时间必须早于失效时间**
- 生效起始时间必须早于失效结束时间
- 违反时提示"生效时间必须小于失效时间，请检查！"，阻止提交
- 边界场景：生效时间与失效时间不能相同（精确到秒）

**校验四：国家+时间区间重复校验**
- 提交时，系统检查选中的每个国家在同一生效时间区间内是否已存在规则记录
- 存在冲突时，列出所有冲突的国家名称，提示"美国、日本 在该时间段内已存在规则，请检查！"，阻止提交
- 冲突判断条件（满足任一即算冲突）：
  - 新规则的生效起始时间 在 已有规则的生效起始时间 与 失效结束时间 之间
  - 新规则的失效结束时间 在 已有规则的生效起始时间 与 失效结束时间 之间
  - 新规则的时间区间完全覆盖已有规则的时间区间
  - 已有规则的时间区间完全覆盖新规则的时间区间
- 以当前已经提交但未保存的"本次申请"为准，仅校验数据库中已存在的规则，不校验本次操作同时提交的其他记录
- 重复校验包含已失效的规则，即无论规则当前状态如何，只要时间区间存在重叠即视为冲突

**校验五：多国家汇总校验**
- 如果选择了多个国家，每个国家都要逐一执行上述校验四
- 假设选择了英国和德国，英国校验通过但德国校验失败：整体拦截提交，提示"德国 在该时间段内已存在规则，请检查！"
- 不分国家展示错误的数量，每个冲突国家独立展示

#### 新增与复制的区别

| 场景 | 区别 |
|------|------|
| 新增 | 表单所有字段为默认空值，国家未选择，进位规则未选择，时间区间为空 |
| 复制 | 表单所有字段预填为被复制规则的对应值，用户可修改任意字段 |

### 7.5 查看规则

- 点击操作列"查看"按钮，弹出只读格式的规则详情弹框
- **弹框标题**：显示"查看规则"
- **字段展示**：所有表单字段原样展示，但均为只读状态，不可编辑
- **底部按钮**：仅显示"关闭"按钮
- **关闭方式**：点击"关闭"按钮或右上角X按钮关闭弹框

### 7.6 失效规则（单条）

**操作流程**：
1. 用户点击某条生效规则操作列的"失效"按钮
2. 弹出失效时间选择弹框
3. 弹框标题显示"设置失效时间"
4. 失效时间默认预设为当前系统时间
5. 用户确认后，该规则的失效时间更新为所选时间
6. 该规则状态自动变为失效，操作列的失效按钮不再显示

**校验规则**：
- 选择的失效时间不能早于该规则的生效起始时间
- 选择的时间精确到秒

**异常场景**：
- 用户选择了失效时间但未点击确定就关闭弹框：操作不生效，规则保持原状态
- 失效时间选择为未来时间：允许，规则在当前时刻到失效时间之间仍为生效状态，到达失效时间后自动变为失效

### 7.7 批量失效

**触发条件**：
- 用户至少勾选了一条规则（在列表行勾选框中选择）
- 勾选的规则中至少有一条为生效状态
- 点击顶部"批量失效"按钮

**操作流程**：
1. 弹出失效时间选择弹框，提示"请选择这批规则的失效时间"
2. 失效时间默认预设为当前系统时间
3. 用户确认后，所有被勾选的生效规则统一失效，失效时间更新为所选时间
4. 已失效的规则不受影响，保持原有失效时间不变

**异常场景**：
- 勾选了5条规则，其中3条生效、2条已失效：批量失效后3条生效规则变更为失效，2条已失效规则不变
- 全部勾选的规则都已失效：点击"批量失效"按钮时提示"所选规则中没有可失效的规则"（或按钮置灰不可点击）
- 批量失效过程中，有规则被其他人提前失效（并发场景）：操作不中断，对已失效的规则不做重复变更

### 7.8 导入导出

#### 模板下载

- 点击"模板下载"按钮，下载Excel格式的导入模板
- 模板包含列头：国家、长宽高进位规则、长宽高进位值、实重进位规则、实重进位值、生效时间、失效时间
- 模板第一行为列头说明，第二行开始为示例数据

#### 导入

- 点击"导入"按钮，弹出文件选择框
- 仅接受 `.xlsx`、`.xls` 格式的文件
- 上传后系统逐行校验，校验结果分两种情况展示

**导入校验规则（共7项）**：

| 校验项 | 校验内容 | 异常处理 |
|--------|---------|---------|
| ① 文件格式校验 | 上传文件是否为.xlsx或.xls格式 | 格式不符时提示"请上传Excel文件（.xlsx或.xls格式）"，不执行后续校验 |
| ② 表头校验 | Excel列头是否与模板一致（列数、列名称） | 列头不匹配时提示"模板格式错误，请下载最新模板后重试" |
| ③ 必填字段校验 | 国家、长宽高进位规则、实重进位规则、生效时间、失效时间不能为空 | 任一必填字段为空时，记录该行校验失败，提示"第X行：国家不能为空"（或对应字段） |
| ④ 进位规则合法性校验 | 进位规则值必须是：向上进位、保留整数、不进位 三者之一 | 非法值时提示"第X行：长宽高进位规则'错误值'无效，可选：向上进位、保留整数、不进位" |
| ⑤ 进位值合法性校验 | 仅当进位规则为"向上进位"时，进位值必填且必须是：1、0.5、0.2、0.1 之一 | 进位规则非向上进位时，进位值必须为空（如果填了值不校验，仅忽略该值）；向上进位时进位值为空或非法值时提示"第X行：长宽高进位值无效" |
| ⑥ 时间格式校验 | 生效时间和失效时间必须为 yyyy-MM-dd HH:mm:ss 格式 | 格式错误时提示"第X行：生效时间格式无效，应为 yyyy-MM-dd HH:mm:ss" |
| ⑦ 时间逻辑校验 | 生效时间 ≤ 当前系统时间 < 失效时间 | 生效时间大于当前时间时提示"第X行：生效时间不能大于当前时间"；生效时间不小于失效时间时提示"第X行：生效时间必须小于失效时间" |

**校验结果展示**：
- **全部通过**：所有行校验通过，提示"导入验证通过！共 N 条数据"
- **存在错误**：提示"导入完成，成功 N 条，失败 M 条"，同时列出前3条错误详情（含行号和错误原因），超出3条的部分提示"还有 X 条错误未显示"
- **导入冲突校验**：校验通过的数据还需要执行与服务端已存在规则的重复校验（同7.4校验四），冲突的规则行同样视为失败
- 校验失败时，已通过的规则数据正常保存，失败的数据不保存

### 7.9 状态流转规则

**状态定义**：
- 规则没有固定的"状态"字段，状态由系统根据当前时间与规则的生效起始时间、失效结束时间动态计算
- **生效**：当前系统时间 ≥ 规则的生效起始时间 且 当前系统时间 ≤ 规则的失效结束时间
- **失效**：当前系统时间 < 规则的生效起始时间（待生效）或 当前系统时间 > 规则的失效结束时间（已过期）

**状态变化触发条件**：
| 触发操作 | 状态变化 | 说明 |
|---------|---------|------|
| 新增规则 | 立即变为生效 | 新规则默认生效起始时间≤当前时间，失效结束时间>当前时间 |
| 失效操作（单条） | 生效 → 失效 | 用户主动失效，失效时间更新为用户选择的时间 |
| 批量失效 | 生效 → 失效 | 多个生效规则同时失效 |
| 规则到达失效时间 | 生效 → 失效（自动） | 系统时间越过规则的失效结束时间，状态自动变为失效 |

### 7.10 列表排序规则

1. **状态优先**：生效状态的规则排在最前面，失效状态的规则排在最后面
2. **生效时间排序**：相同状态的规则按生效起始时间从新到旧排列（最近生效的排在最前）
3. **分页展示**：支持分页，默认每页展示固定数量（具体数量由UI设计决定）

### 7.11 字段汇总说明

| 信息项 | 说明 | 示例值 |
|--------|------|--------|
| 国家 | 规则适用的国家列表，支持多选，多个国家用逗号分隔合并为一条记录 | 英国,德国 |
| 长宽高进位规则 | 长宽高计费时的进位方式，枚举值：向上进位、保留整数、不进位 | 向上进位 |
| 长宽高进位值 | 进位基准值，仅当进位规则为"向上进位"时有值；枚举值：1、0.5、0.2、0.1 | 1 |
| 实重进位规则 | 实际重量计费时的进位方式，枚举值：向上进位、保留整数、不进位 | 不进位 |
| 实重进位值 | 进位基准值，仅当进位规则为"向上进位"时有值；枚举值：1、0.5、0.2、0.1 | 0.5 |
| 生效时间 | 规则生效的起始时刻，格式：yyyy-MM-dd HH:mm:ss | 2026-03-01 09:00:00 |
| 失效时间 | 规则失效的时刻，格式：yyyy-MM-dd HH:mm:ss | 2026-06-01 09:00:00 |

### 2. 造数需求

| 数据类别 | 数据要求 | 使用场景 |
|---------|---------|---------|
| 生效规则（10条以上） | 涵盖多国家（至少5个国家）、多种进位规则组合、不同的生效时间区间 | 验证列表展示、搜索筛选、失效操作、分页 |
| 失效规则（5条以上） | 生效时间区间完全在当前时间之前 | 验证排序、状态展示、操作列按钮显示 |
| 时间冲突数据 | 同一国家（如英国）在同一时间区间存在多条规则 | 验证新增时的重复校验拦截 |

### 3. 风险点说明

| 风险类型 | 风险描述 | 应对措施 |
|---------|---------|---------|
| 业务风险 | 系统时间与用户本地时间不一致，导致列表状态计算结果与用户预期不符 | 状态计算以服务器时间为准，前端仅做动态刷新展示 |
| 数据风险 | 导入数据量过大（如超过500行），逐行校验导致响应缓慢 | 前端限制单次导入行数不超过500行，超出时提示分批导入 |
| 系统风险 | 多人同时操作时出现并发冲突（A确认新增同时B也在操作相同国家） | 提交时服务端做原子化校验和写入，避免并发场景下产生重复规则 |
| 业务风险 | 批量失效操作不可逆，误操作导致大量规则同时失效 | 批量失效前弹出二次确认，提示本次将影响的规则数量，用户确认后才执行 |
| 数据风险 | 新增时选择的生效时间区间跨度过大（如10年），长期占用规则区间 | 建议业务层做时间区间合理性校验，但不做强制限制，由运营自行把控 |
| 展示风险 | 国家名称较多时（如超过10个国家合并为一条规则），表格中显示被截断 | 截断内容通过鼠标悬停浮层查看完整国家列表 |

## 九、非功能需求

### 1. 多语言

- **是否支持多语言（必选）**：是，默认中英文
- 需要翻译的内容：搜索区文案、按钮文案（新增/批量失效/模板下载/导入）、表格列名（序号/状态/国家/长宽高进位规则/长宽高进位值/实重进位规则/实重进位值/生效时间/失效时间/操作）、弹框标题和字段标签、校验提示文案、空状态提示
- 不需要翻译的内容：国家名、规则枚举值（向上进位/保留整数/不进位）、进位值（1/0.5/0.2/0.1）、时间值

### 2. 多时区

- **是否支持多时区（必选）**：是，需要支持多时区
- 生效时间和失效时间的展示根据当前用户所在的时区自动转换
- 时间校验（生效时间≤当前时间）使用服务端统一标准时间

### 3. 安全合规

- 进位规则属于计费核心配置，任何规则变更操作均需记录操作日志
- 操作日志需包含：操作人、操作时间、操作类型（新增/修改/失效/导入）、操作内容描述
- 导入Excel文件需做病毒扫描和安全校验

### 4. 权限

| 权限类型 | 功能名称 | 是否做权限管控 |
|---------|---------|-------------|
| 菜单权限 | 进位规则管理页面 | 是，仅授权用户可见 |
| 功能权限 | 新增/复制规则 | 是 |
| 功能权限 | 批量失效 | 是 |
| 功能权限 | 导入 | 是 |
| 功能权限 | 模板下载 | 是 |
| 功能权限 | 查看规则（行内） | 是 |
| 功能权限 | 失效规则（行内） | 是 |
| 数据权限 | 规则数据 | 否，全局数据 |

### 5. 性能

| 性能维度 | 要求 |
|---------|------|
| 列表查询 | 500条数据加载到页面展示，不超过1秒 |
| 新增/复制规则 | 从提交到刷新列表，不超过1秒 |
| 失效/批量失效 | 从提交到刷新结果，不超过1秒（批量50条以内） |
| 导入校验 | 100行数据的Excel校验，不超过2秒 |
| 并发场景 | 支持至少50个用户同时使用 |

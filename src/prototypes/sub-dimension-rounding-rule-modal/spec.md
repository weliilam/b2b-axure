# 材积进位规则弹框 - 规格文档

## 1. 基本信息

| 项目 | 说明 |
|------|------|
| **原型名称** | sub-dimension-rounding-rule-modal |
| **原型标题** | 材积进位规则 |
| **功能说明** | 管理材积进位规则配置，支持查询、新增、批量失效、模板下载、导入、批量删除等操作；每行支持行内失效和删除 |
| **适用平台** | PC Web |
| **界面类型** | Modal 弹框（无标题栏、无底部按钮栏） |
| **弹框宽度** | 1200px |

## 3. 界面结构

### 3.1 搜索区（query-bar）

参考 B2B 订单列表页的 `query-bar` 样式，采用 `.query-bar > .filter-row > .filter-group` 三层结构，无背景色，仅底部边框。

| 字段 | 控件类型 | 说明 |
|------|---------|------|
| 国家 | Input（带搜索图标） | 输入搜索国家关键词，支持清除 |
| 状态 | Select（下拉框） | 选项：所有、待生效、生效、失效，支持清除 |
| 产品名称 | Input（带搜索图标） | 输入搜索产品名称，支持清除 |
| 查询 | Button（蓝色主题） | 带搜索图标的查询按钮，固定宽度不伸缩 |

**布局**：搜索区元素水平排列，前三个字段等分伸缩，查询按钮放在最右侧固定宽度。

### 3.2 操作按钮区（rule-action-bar）

水平排列在搜索区下方，左右 16px 内边距与搜索区对齐。

| 按钮 | 图标 | 样式 | 功能 |
|------|------|------|------|
| 新增 | PlusOutlined (+) | 默认蓝边按钮 | 弹出新增规则表单弹框 |
| 批量失效 | ClockCircleOutlined (时钟) | 默认蓝边按钮 | 将选中的多条规则设为失效 |
| 模板下载 | DownloadOutlined (下载) | 默认蓝边按钮 | 下载 Excel 导入模板 |
| 导入 | UploadOutlined (上传) | 默认蓝边按钮 | 批量导入规则 |
| 批量删除 | DeleteOutlined (删除) | 红色边框按钮 | 删除选中的多条规则 |

### 3.3 数据表格（rule-table）

无分页，含复选框多选，带边框圆角容器。

| 列名 | 数据字段 | 宽度 | 说明 |
|------|---------|------|------|
| 复选 | — | 40px | 复选框多选行 |
| 序号 | `seq` | 56px | 行序号 |
| 状态 | `status` | 70px | Tag 标签：待生效=蓝色、生效=绿色、失效=灰色 |
| 国家 | `country` | 160px | 逗号分隔的多国家名，每个国家渲染为 Tag 标签 |
| 长宽高进位规则 | `dimensionRule` | 160px | 文本展示 |
| 长宽高进位值 | `dimensionValue` | 140px | 文本展示，仅向上进位时有值 |
| 实重进位规则 | `weightRule` | 150px | 文本展示 |
| 实重进位值 | `weightValue` | 130px | 文本展示，仅向上进位时有值 |
| 生效时间 | `effectTime` | 175px | 时间文本 |
| 失效时间 | `expireTime` | 175px | 时间文本 |
| 操作 | — | 180px | 操作链接，固定在右侧 |

#### 操作列规则

| 按钮 | 条件 | 颜色 | 功能 |
|------|------|------|------|
| 失效 | 状态 ≠ "失效" 时显示 | 黄色 (#faad14) | 将单条记录置为失效 |
| 删除 | 状态 = "待生效" 时显示 | 红色 (#ff4d4f) | 删除单条记录 |

### 3.4 新增/修改表单弹框（RuleFormModal）

点击"新增"或"操作列修改"时弹出的独立弹框。

| 属性 | 值 |
|------|-----|
| 弹框宽度 | 720px |
| 弹框标题 | 新增规则 / 修改规则（蓝色竖线 + 标题文字） |
| 底部按钮 | 取消（默认样式）、确定（蓝色主题） |

#### 表单字段

表单采用 2 列网格布局（`.rule-form-grid`），生效时间在网格下方独立一行。

| 字段名 | 标签 | 控件类型 | 必填 | 条件显示 | 说明 |
|--------|------|---------|------|---------|------|
| `country` | 国家 | Select (mode="multiple", showSearch) | 是 | — | 可多选、可搜索国家 |
| `dimensionRule` | 长宽高进位规则 | Select | 是 | — | 选项：向上进位、保留整数、不进位 |
| `dimensionValue` | 长宽高进位值 | Input | 是 | 仅当 `dimensionRule` = "向上进位" | 输入进位数值 |
| `weightRule` | 实重进位规则 | Select | 是 | — | 同上四个选项 |
| `weightValue` | 实重进位值 | Input | 是 | 仅当 `weightRule` = "向上进位" | 输入进位数值 |
| `dateRange` | 生效时间 | DatePicker.RangePicker (showTime) | 是 | — | 选择生效时间区间（含时分秒） |

#### 表单交互

- **新增**：表单全部清空，国家多选为空；保存时多个国家会自动拆分为多条独立记录，每个国家一条
- **修改**：预填选中行数据，国家多选自动解析逗号分隔字符串为数组，时间区间自动转为 dayjs 数组
- **条件显示**：长宽高进位值 和 实重进位值 字段通过 `Form.useWatch` 监听对应规则的选择，仅当选择"向上进位"时渲染输入框，选择其他规则时自动隐藏

### 3.5 新增/修改弹框底部按钮

| 按钮 | 样式 | 功能 |
|------|------|------|
| 取消 | 默认边框按钮 | 关闭弹框，不清除表单 |
| 确定 | 蓝色主题按钮 (#1D4CD2) | 触发表单校验，通过后调用 onOk |

## 4. 交互逻辑

### 4.1 搜索
- 输入国家/产品名称关键词（支持模糊匹配）、选择状态过滤条件
- 点击"查询"按钮执行搜索，表格刷新显示符合条件的数据

### 4.2 新增
- 点击顶部"新增"按钮，弹出新增规则表单弹框
- 填写所有必填字段后点"确定"
- 校验通过后提示"新增成功"，关闭弹框

### 4.3 行内失效
- 每行操作列显示"失效"链接（黄色）
- 仅状态 ≠ "失效" 的行显示该按钮
- 点击后提示"记录 [国家] 已失效"

### 4.4 行内删除
- 每行操作列显示"删除"链接（红色）
- 仅状态 = "待生效" 的行显示该按钮
- 点击后提示"记录 [国家] 已删除"

### 4.5 批量失效
- 勾选多条记录后点击顶部"批量失效"按钮
- 将选中的记录全部置为失效状态

### 4.6 批量删除
- 勾选多条记录后点击顶部"批量删除"按钮（红色边框）
- 删除选中的记录

### 4.7 模板下载
- 点击后下载 Excel 导入模板文件（预留功能）

### 4.8 导入
- 点击后打开文件选择器，支持导入 Excel 数据（预留功能）

### 4.9 关闭弹框
- 点击弹框右上角 X 按钮可关闭弹框
- 触发 onCancel 事件

## 5. 状态说明

| 状态值 | 含义 | Tag 颜色 | 可操作项 |
|--------|------|---------|---------|

## 7. 实现备注

- **技术栈**：React + TypeScript + Ant Design 5
- **共享样式**：`@import "../../styles/modal-shared.css"` 提供弹框统一基础样式
- **核心组件**：Modal、Table、Button、Input、Select、Tag、Form、DatePicker.RangePicker
- **图标库**：@ant-design/icons（PlusOutlined、ClockCircleOutlined、DownloadOutlined、UploadOutlined、DeleteOutlined、SearchOutlined）
- **日期库**：dayjs（用于 DatePicker 值转换）
- **搜索区样式**：与 order-list 列表页一致，`.query-bar > .filter-row > .filter-group > .fl-label`
- **条件渲染**：使用 `Form.useWatch` 监听进位规则字段，条件显示对应进位值输入框
- **国家多选**：数据存储为逗号分隔字符串，表格渲染为多个 Tag，表单使用 `mode="multiple"` Select
- **操作列**：函数式列定义，接收 `onDisable` 和 `onDelete` 回调，根据状态条件渲染操作按钮
